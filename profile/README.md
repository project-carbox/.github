## 🏛️ About Carbox
**Carbox** is a high-throughput computational biology and mathematical crystallography Python library for identifying anomalous carboxyl–carboxyl interactions, low-barrier hydrogen bonds (LBHBs), empirical pKa perturbation shifts, local electron density integration, and automated refinement restraints for **REFMAC5** and **Servalcat**.

### 🌟 Featured Repositories
- 📦 **[carbox](https://github.com/project-carbox/carbox):** The pure Python scientific library, terminal CLI, mathematical core, unit test suite, and peer-reviewed monograph LaTeX manuscripts.

### 🔗 Companion Organizations
- 🖥️ **[CarboxMol Organization](https://github.com/carboxmol):** The official home of the 3D molecular graphics workbench, CLI, and WebApp Studio.
- 🌐 **[Live Web Studio](https://carboxmol.github.io):** Interactive 3D crystallographic modeling in any modern web browser.
